03 / CHECK & SAVE

Validate before saving

Validation checks the JSON contract, references, and SQL rules using a transaction that is rolled back. Saving rechecks everything and commits the complete card.

Ready. Load a card to begin.

Imports create new draft or submitted packages. Existing packages are never overwritten. Submission timestamps are assigned by PostgreSQL; original imported timestamps remain in the source artifact.

04 / EXPLORE

Refresh the graph

After a successful save, refresh Neo4j to project the current PostgreSQL records. A refresh failure does not undo your saved card.

Open Neo4j Browser using the HTTP port in your Docker settings (7474 by default). Connect with your configured Bolt port and credentials.
